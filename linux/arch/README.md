# Arch Linux

App bootstrap for Arch Linux.

## Highlights

`install-apps.sh` installs via `pacman`: ghostty, nautilus, lazygit, virtualbox, tmux, zsh, nvim, chromium-browser, zen-browser-bin, podman (+desktop), steam, pika-backup, spotify-launcher, fzf. Also installs oh-my-zsh and [opencode](https://opencode.ai) via curl.

# Fedora

App bootstrap for Fedora.

## Highlights

- `setup.sh`: installs apps via `dnf` (chromium-browser, snap, fzf, nvim, lsd, zsh, discord, nautilus, virt-manager, ghostty), oh-my-zsh, lazygit (via copr), spotify (snap), nvm, opencode, obsidian/pika-backup/rustdesk (flatpak), nordvpn, gh cli
- `remove-unused.sh`: removes default KDE/GNOME bloat apps (akregator, dragon, elisa, kmines, libreoffice, mpv, okular, gwenview, kmail, etc.) and `kitty`, `nvtop`

# Ghostty (macOS)

Config for [Ghostty](https://ghostty.org), a terminal emulator.

![ghostty](./ghostty.png)

## Highlights

- `Blazer` theme with Hack Nerd Font
- Transparent, blurred background (opacity `0.8`)
- Hidden titlebar and window buttons
- Dimmed unfocused splits

## Setup

`setup.sh` symlinks `config` to `~/Library/Application Support/com.mitchellh.ghostty/config`.

See also the [Linux variant](../../linux/ghostty).
